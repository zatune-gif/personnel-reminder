# 人員管理リマインダー Bot

Slackを通じてチームメンバーの状態を定期的に把握し、管理者に適切なタイミングで声かけを促すBotです。

## できること

- **月2回の状態チェックイン**をメンバーのSlack DMに自動送信
- **年1回のサーベイ**でメンバーの傾向・特性を把握
- 回答内容をAIが分析し、**管理者に状態レポートを通知**
- アラートレベルに応じて通知の緊急度を変える（6段階）
- 2回連続で未回答のメンバーも管理者に通知

---

## 必要なもの

| 必要なもの | 用途 | 費用 |
|---|---|---|
| Slack ワークスペース | Bot の動作環境 | 無料プランで可 |

| Python 3.10 以上 | Bot の実行環境 | 無料 |
| 常時起動できるPC or サーバー | Bot を動かし続ける場所 | — |

## セットアップ手順

### Step 1: Python の確認

コマンドプロンプト（Windows）またはターミナル（Mac）を開いて以下を実行してください。

```
python --version
```

`Python 3.10.x` 以上が表示されればOKです。  
表示されない場合は https://www.python.org/downloads/ からインストールしてください。

---

### Step 2: コードをダウンロード

```
git clone https://github.com/（リポジトリURL）
cd personnel-reminder
```

git が使えない場合は、GitHubページの「Code → Download ZIP」でダウンロードして解凍してください。

---

### Step 3: Slack アプリを作成する

#### 3-1. アプリの作成

1. https://api.slack.com/apps にアクセスし、Slackアカウントでログイン
2. **「Create New App」** をクリック
3. **「From scratch」** を選択
4. App Name に任意の名前（例: `人員管理Bot`）を入力し、使用するワークスペースを選択
5. **「Create App」** をクリック

#### 3-2. Socket Mode を有効化（App-Level Token の取得）

1. 左メニューの **「Socket Mode」** をクリック
2. **「Enable Socket Mode」** をオンにする
3. Token Name に任意の名前（例: `socket-token`）を入力
4. **「Generate」** をクリック
5. 表示された `xapp-...` から始まるトークンをコピーして保存する

#### 3-3. Bot のスコープ設定

1. 左メニューの **「OAuth & Permissions」** をクリック
2. **「Bot Token Scopes」** セクションで **「Add an OAuth Scope」** をクリック
3. 以下の5つを追加する

| スコープ名 | 用途 |
|---|---|
| `chat:write` | メッセージ送信 |
| `im:write` | DM送信 |
| `im:read` | DM読み取り |
| `im:history` | DM履歴の参照 |
| `users:read` | ユーザー情報の取得 |

#### 3-4. イベント購読の設定

1. 左メニューの **「Event Subscriptions」** をクリック
2. **「Enable Events」** をオンにする
3. **「Subscribe to bot events」** セクションで **「Add Bot User Event」** をクリック
4. `message.im` を追加する

#### 3-5. インタラクティビティの有効化（アンケートモーダル用）

1. 左メニューの **「Interactivity & Shortcuts」** をクリック
2. **「Interactivity」** をオンにする
3. Request URL に `https://example.com` と入力して保存（Socket Modeでは実際には使われません）

#### 3-6. ワークスペースにインストール（Bot Token の取得）

1. 左メニューの **「OAuth & Permissions」** をクリック
2. ページ上部の **「Install to Workspace」** をクリック
3. **「許可する」** をクリック
4. 表示された `xoxb-...` から始まるトークンをコピーして保存する

#### 3-7. 自分の Slack ID を確認する

1. Slack を開き、左サイドバーで自分の名前をクリック
2. **「プロフィールを表示」** → 右上の **「…」** → **「メンバーIDをコピー」**
3. コピーした `U` から始まるIDを保存する（管理者IDとして使います）

---

### Step 4: Google API Key を取得する

1. https://aistudio.google.com/ にアクセスし、Googleアカウントでログイン
2. 左メニューの **「Get API key」** をクリック
3. **「Create API key」** をクリック
4. 表示された `AIza...` から始まるキーをコピーして保存する

---

### Step 5: 設定ファイルを作成する

ダウンロードしたフォルダ内の `.env.example` を `.env` という名前でコピーします。

**Windows の場合:**
```
copy .env.example .env
```

**Mac の場合:**
```
cp .env.example .env
```

`.env` をテキストエディタで開き、Step 3・4 で保存した情報を入力します。

```
SLACK_BOT_TOKEN=xoxb-（Step 3-6 でコピーしたトークン）
SLACK_APP_TOKEN=xapp-（Step 3-2 でコピーしたトークン）
GOOGLE_API_KEY=AIza-（Step 4 でコピーしたキー）
ADMIN_SLACK_ID=U（Step 3-7 でコピーした自分のSlack ID）
```

---

### Step 6: 必要なライブラリをインストールする

```
pip install -r requirements.txt
```

---

### Step 7: Bot を起動する

```
python main.py
```

`Bot started` と表示されれば起動成功です。

---

### Step 8: 初期設定（Slack から実施）

Bot が起動したら、Slack で Bot とのDMを開いて初期設定を行います。

#### グループを作成する

部署やクラス単位でグループを作ります。

```
グループ作成 営業部 <@担当管理者のSlackID>
```

管理者自身もアンケート対象にする場合は、自分もメンバーとして追加してください。

#### メンバーを追加する

```
メンバー追加 田中太郎 <@田中さんのSlackID> グループ名 役割
```

例:
```
メンバー追加 田中太郎 <@U012ABCDEF> 営業部 主任
```

#### 年次サーベイを送る

メンバー追加後、まず年次サーベイを送ってプロファイルを作成します。

```
年次サーベイ送信
```

#### 月次チェックインを送る

年次サーベイの回答が完了したメンバーに送れます。

```
チェックイン送信
```

## 管理者コマンド一覧

Bot とのDMで使えるコマンドです。

| コマンド | 内容 |
|---|---|
| `グループ作成 グループ名 <@管理者ID>` | グループを作成する（ADMIN のみ） |
| `グループ一覧` | 全グループを表示する（ADMIN のみ） |
| `メンバー追加 名前 <@SlackID> グループ名 役割` | メンバーを追加する（ADMIN のみ） |
| `メンバー追加 名前 <@SlackID> 役割` | 自分のグループにメンバーを追加する |
| `メンバー一覧` | 自分のグループのメンバーを表示する |
| `グループ変更 <@SlackID> 新グループ名` | メンバーを別グループに移動する |
| `年次サーベイ送信` | 自分のグループに年次サーベイを送る |
| `チェックイン送信` | 自分のグループに月次チェックインを送る |

## アンケートの内容

### 年次サーベイ（年1回・自動送信）

メンバーの傾向・特性を把握するためのサーベイです。回答内容はAIがプロファイル生成に使用します。

| # | 質問 | 回答形式 |
|---|---|---|
| Q1 | 困ったとき、誰かに相談することができますか？ | 1〜5（1=ほぼできない） |
| Q2 | 締め切りや責任が重なると、どちらかというと？ | 1〜5（1=消耗する） |
| Q3 | 自分の取り組みや成果を認めてもらうことはどれくらい大切ですか？ | 1〜5（1=あまり気にしない） |
| Q4 | 環境や仕事内容が変わることへの適応は？ | 1〜5（1=苦手） |
| Q5 | 気持ちが重いと感じたとき、どう切り替えますか？ | 自由記述 |

### 月次チェックイン（月2回・自動送信）

現在の状態を把握するための定期チェックです。毎月1日と15日に自動送信されます。

| # | 質問 | 回答形式 |
|---|---|---|
| Q1 | 最近の仕事量はどう感じますか？ | 1〜5（1=少なすぎ・3=ちょうどよい・5=多すぎ） |
| Q2 | 仕事や活動への前向きさはどうですか？ | 1〜5（1=低い） |
| Q3 | 最近困っていること・行き詰まっていることはありますか？ | 自由記述 |
| Q4 | 周囲とのコミュニケーションは取れていますか？ | 1〜5（1=取れていない） |

## リマインド発火のしくみ

AIが以下の3つを組み合わせて総合的に判断します。

```
今回のスコア（業務量・モチベ・コミュ・困りごと）
        ＋
過去3回分のスコアトレンド（悪化傾向かどうか）
        ＋
年次サーベイで把握した傾向による補正
        ↓
アラートレベルを決定 → 必要なら管理者にDM通知
```

**傾向による補正の例**

| 傾向 | 補正内容 |
|---|---|
| 抱え込みがちな人 | 同じスコアでも1段階早くアラートを上げる |
| プレッシャーに弱い人 | 業務量が多い場合は特に早めに通知 |

**2回連続未回答の場合**  
回答がないこと自体をリスクと判断し、管理者に 👀 通知します。

---

## アラートレベルについて

メンバーの回答をAIが分析し、以下のレベルで管理者に通知します。

| レベル | 通知 | 内容 |
|---|---|---|
| clear / stable | なし | 問題なし |
| 👀 注視 | あり | 声かけ不要。状況を頭に置いておく |
| 📅 今週中に声かけを | あり | 今週中に機会を作って声をかける |
| ⚠️ 早めに1on1を | あり | できるだけ早く1on1を設定する |
| 🚨 即日対応 | あり | 今日中に対応する |

2回連続でチェックインに未回答の場合も 👀 通知が届きます。

### 通知例

**例1: モチベーション低下傾向（承認欲求が高めのメンバー）**

```
📅 【今週中に声かけを】 鈴木さん の状態レポート

状況: モチベーションが3回連続で低下。業務量は適切で
      コミュニケーションも取れているため、成果が認められて
      いないことへの不満が原因の可能性が高い。

対応方針: 直近の成果を具体的に言葉にして伝える
          1on1を今週中に設定する。

声のかけ方: 「最近どう？」より「○○の対応、うまくいってたよ」
            と成果を先に伝えると話が広がりやすい。
```

**例2: 2回連続未回答（抱え込みがちなメンバー）**

```
👀 【注視】 田中さん の状態レポート

状況: 月次チェックインへの回答が2回連続でありません。

対応方針: 声かけは不要ですが、次回回答があるか注目して
          ください。
```

## Bot を常時起動させるには

Bot は起動している間だけ動作します。PCを閉じると止まってしまいます。

**簡単な方法:** 使用しているPCを常時起動させておく。

**サーバーを使う方法（無料）:**  
[Railway](https://railway.app/) や [Fly.io](https://fly.io/) などの無料サービスにデプロイすることで、PCを閉じても動き続けます。設定方法は別途ご相談ください。

## よくある質問

**Q. メンバーのアンケート回答内容は本人に見えますか？**  
A. 見えません。回答はDBに保存され、担当管理者のみが通知を受け取ります。

**Q. 年次サーベイを完了していないとどうなりますか？**  
A. 月次チェックインの回答時にメッセージが届き、先に年次サーベイを完了するよう案内されます。

**Q. Google API Key は無料でどれくらい使えますか？**  
A. 1日1,500リクエストまで無料です。数十人規模のチームであれば無料枠で十分です。

**Q. 複数のグループを管理できますか？**  
A. できます。部署やクラス単位でグループを作り、それぞれに管理者を設定してください。
